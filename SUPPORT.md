# Support

Thanks for using Citrate. Here's the fastest path to help:

| I want to… | Go to |
|---|---|
| **Read docs / run the stack locally** | [docs.citrate.ai](https://docs.citrate.ai) · `citrate-docs/LOCAL_STACK.md` |
| **Ask a usage or design question** | [GitHub Discussions](https://github.com/orgs/CitrateNetwork/discussions) |
| **Report a bug** | Open an issue in the relevant repo (use the bug template) |
| **Request a feature / propose a change** | Open an issue first (feature template) — especially for non-trivial work |
| **Report a security vulnerability** | **Email security@citrate.ai** — never a public issue. Coordinated disclosure, 90-day window. See [`SECURITY.md`](SECURITY.md) |
| **Membership / getting involved** | [citrate.ai](https://citrate.ai) · hello@citrate.ai |
| **Commercial / partnerships** | Partnerships@citrate.ai |

**Please don't** use the issue tracker for support questions that aren't a bug or a
concrete feature request — Discussions keeps issues actionable for everyone.

Citrate is **open-core**: the chain & consensus, SDKs, types, docs, explorer, and agent
runtime are Apache-2.0; the desktop app and monetized services are source-available under
BUSL-1.1 (free for personal/non-commercial use, membership for commercial use).
